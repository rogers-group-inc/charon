            Charon connects to each host over SSH or WinRM with the credential you choose and runs the
            agent installer as root / Administrator. The host’s SSH host key or WinRM certificate
            is pinned the first time Charon connects, and a later change is refused (Server Settings → Web Server
            → Pinned server identities). The installer leaves a single-use enrollment code, valid for
            10 minutes and readable only by root / SYSTEM.
          

          

            A push-deployed agent enrolls on its own only once the agent runs as a background service (a later agent
            release). Until then the deployment shows Awaiting enrollment; enroll the agent manually with an
            invitation code.
